Metric definitions

  • Lead cards count contacts created in the period using their current status. New leads today and current queue totals are independent of the selected period.
  • Accepted sends use SMTP acceptance timestamps and include marketing and transactional mail. Failed-job counts use creation timestamps.
  • Open/click rates use tracked marketing messages accepted in the period. Proxies/scanners affect results; SMTP acceptance does not prove inbox placement.
  • Affiliate clicks and downloads count events, not purchases. The all-time daily chart displays the latest 30 days.
